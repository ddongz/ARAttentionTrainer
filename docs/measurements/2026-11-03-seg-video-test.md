
# SelfieSeg 测试视频分割结果（2026-11-03）

> 视频：`Assets/StreamingAssets/test.mp4`（960×544，30fps，147s）
> 模型：`Assets/Models/selfie_seg_landscape.onnx`（输入 1×3×144×256，输出 1×1×144×256）
> 方法：Python + onnxruntime，RGB/255（与 Unity TextureConverter 默认 0–1 一致）；
> 截图目录：`Builds/seg-test/`（不提交）

## 结论

1. **人物主体分割可用**：头、肩、手臂、躯干、衣物都能被掩码覆盖；
   256×144 的分辨率导致边缘呈块状/柔边，但轮廓清楚。
2. **无人物帧（镜头转开）掩码接近 0**：全视频 148 个抽样帧中，
   最低 0、最高 25.9%、平均 6.7%；镜头转开的 330–600 帧基本为 0。
3. **存在背景误检**：
   - 左侧玻璃/窗框/反光会出现 0.3–0.5 的灰色掩码；
   - 老师身后的白板边缘/白板面也会被部分覆盖（>0.5）；
   - 如果不处理，青色高亮会“连到背景”，看起来分割错误。
4. **处理方案（已实现）**：
   - 高亮只取 **YOLO 目标人框内**的掩码（shader `_TargetRect`，外扩 4%）；
     人框外左侧反光/海报/其他人直接不显示；
   - 阈值从 0.35/0.6 提高到 **0.5/0.75**，去掉人框内白板的低置信区域；
   - seg 只在 **人体 + 人脸都确认** 时才推理（`SelfieSegRunner.SetActive`），
     人/脸丢失即暂停，省 CPU；
   - 高亮层颜色青色、边缘加亮，便于看贴合度。
5. **剩余限制**：
   - 人框直接贴着老师时，身后白板与人体重叠区域的掩码可能仍有一点高亮；
   - 256×144 的上采样边缘较软，后续做遮挡时可能需要边缘细化/时域平滑；
   - 高亮当前会覆盖画面中所有被 seg 判定为人的区域（但被目标人框裁掉）；
     如果同框有多人且人框交叠，仍可能显示到旁人，后续可加“只保留目标人框内最大连通域”。

## 下一步（真机）

- 装上最新 APK，人+脸确认后看青色高亮是否贴在老师身上；
- 如果高亮**整体偏移**：检查 `SegMaskHighlight` 的单应映射/眼相机；
- 如果高亮**只到白板/背景**：调 `_TargetRect` 外扩比例或阈值；
- 如果边缘太软/缺手臂：考虑掩码时域平滑或换更高分辨率模型；
- 分割确认正确后，再用 `MaskErase` 做精灵“躲到老师身后/探头”的遮挡交互。
